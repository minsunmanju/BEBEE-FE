## 📌 프로젝트 소개

<div align="center">

> **LG CNS AM CAMP 03기 1조 공공 도메인**
>
> 🐝 **비비(Be Bee)** 는 장애인과 도우미를 연결하는 스마트 매칭 플랫폼입니다.
> OCR 기반 신원 검증, 실시간 채팅, 가상화폐(꿀) 결제 시스템을 통해
> 더 안전하고 편리한 도움의 연결을 만들어갑니다.

</div>

## ✨ 주요 기능

<br/>

### 🔍 OCR 기반 회원정보 검증
> 신분증 OCR 인식을 통해 신뢰할 수 있는 사용자 인증을 제공합니다.

### 💬 실시간 채팅 매칭
> 장애인과 도우미가 실시간 채팅으로 빠르게 연결됩니다.

### 🍯 가상화폐 **"꿀"** 결제 시스템
> 플랫폼 전용 가상화폐 **꿀**을 활용한 간편하고 안전한 결제 시스템입니다.

<br/>

## 🚀 로컬 실행 방법

```bash
# 패키지 설치
pnpm install

# 개발 서버 실행
pnpm dev
```

> ⚠️ **Node.js** 및 **pnpm** 이 설치되어 있어야 합니다.
